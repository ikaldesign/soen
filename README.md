# soen
CSS Framework
v0.3.10

Tone: Calm, meditative, timeless. Feels like still water or reflection.
Meaning / Origin: Derived from the Japanese Zen name “Sōen” (僧円), meaning simplicity, wisdom, or completeness.
Why it fits: Embodies the “be like water” philosophy literally. Philosophical, spiritual undertones without feeling heavy-handed.
Visual Direction:

Minimal sans-serif logo, subtle brush-like curves.

Earth and mist palette — muted blues, soft grays, and ivory.
Subnames:

Soen Core, Soen Playground, Soen Docs, Soen Modules.
→ Feels like a unified design practice rather than a product suite.

Core traits: meditative · minimal · grounded · timeless
Mood: reflective simplicity — like ink on still water
Palette direction: warm gray, muted blue, pale ivory
Typography: modern sans with subtle humanist warmth (e.g., Söhne, Noto Sans, Inter with wide spacing)
Iconography: circular flow mark, Zen enso-like brush circle, or wave ring
Tone words: calm · clarity · intention · quiet mastery
